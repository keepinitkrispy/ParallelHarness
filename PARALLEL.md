# Parallel

Personal Android agent UI derived from AndroidHarness (MIT).

- Package: dev.keepinitkrispy.parallel
- Default local model: Qwen3-4B Q4_K_M at http://127.0.0.1:8080/v1
- Parallel Processing kernel is injected into every agent system prompt.
- Full Auto is the fresh-install default.
- Shizuku permission is requested automatically when the service is running.
